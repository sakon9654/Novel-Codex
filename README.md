# Novel Codex

แกนกลางสำหรับสร้าง วางแผน เขียน และตรวจแก้นิยายด้วยเอเจนต์ โดยเก็บวิธีทำงานที่นำกลับมาใช้ซ้ำได้แยกจากต้นฉบับของนิยายแต่ละเรื่อง

## หลักการ

- เลือกคำและจังหวะภาษาให้เหมาะกับเรื่องโดยอัตโนมัติ ไม่รอให้ผู้ใช้เตือนทุกครั้ง
- รักษาเสียงหลักของเรื่อง แต่ปรับความเร็ว น้ำหนัก และระยะกล้องตามหน้าที่ของแต่ละฉาก
- เก็บสไตล์เป็นคุณลักษณะที่ผสมกันได้ ไม่เลียนแบบสำนวนเฉพาะตัวของนักเขียน
- แยกข้อเท็จจริงของเรื่องออกจากคำแนะนำด้านงานเขียน เพื่อให้ตรวจความต่อเนื่องได้
- ให้ผู้เขียนตัดสินใจเรื่องเจตนา ส่วนเอเจนต์รับผิดชอบคุณภาพพื้นฐานและความสม่ำเสมอ

## ส่วนประกอบปัจจุบัน

- `AGENTS.md` — กติกาพื้นฐานสำหรับเอเจนต์ทุกตัว
- `skills/prose-style-director/` — เลือกและควบคุมสำนวน คำ และจังหวะภาษา
- `skills/story-continuity/` — บังคับอ่านบริบทก่อนเขียน และคุม canon, timeline, ความรู้/ความลับและการเปิดเผย
- `templates/style-profile.md` — บันทึกเสียงหลักของนิยายแต่ละเรื่อง

## วิธีใช้กับนิยายหนึ่งเรื่อง

คัดลอก `templates/style-profile.md` ไปไว้ในโปรเจกต์นิยาย กำหนดเฉพาะสิ่งที่รู้ แล้วปล่อยช่องที่เหลือให้เอเจนต์อนุมานจากแนวเรื่อง กลุ่มผู้อ่าน และตัวอย่างต้นฉบับ เมื่อเริ่มเขียนหรือแก้ร้อยแก้ว เอเจนต์จะใช้สกิลกำกับสำนวนโดยอัตโนมัติ
