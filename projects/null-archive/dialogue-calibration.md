# NULL ARCHIVE — Dialogue Calibration v0.2

สถานะ: ข้อกำหนดสไตล์เฉพาะเรื่องจากคำแก้ของผู้เขียน (ไม่ใช่ canon เหตุการณ์)
Branch: novel/cosmic-horror

## หลักการหลัก
- เขียนภาษาไทยร่วมสมัยที่ฟังเป็นคนพูดจริง เลือกคำตามบริบทและหน้าที่ของบทสนทนา
- ผู้บรรยายบุคคลที่สามแบบสังเกตเหตุการณ์ ไม่บอกข้อสรุปหรือความคิดในใจตัวละครโจ่งแจ้ง
- ไม่ตัดบทพูดให้ห้วนโดยไม่จำเป็น: บทสนทนาควรครบความ มีจังหวะ ความต่อเนื่อง และน้ำเสียงเฉพาะตัว
- ไม่ขึ้นย่อหน้าแยกทีละคำเพื่อเร่งความระทึก ถ้าเหตุการณ์เดียวกันเล่าต่อเนื่องได้ให้ใช้ประโยคต่อเนื่อง
- ประโยคบรรยายที่ผู้เขียนปรับเทียบ: «ไม่มีเสียงตอบรับ» เหมาะกว่าคำว่า «ไม่มีเสียงตอบ» ในบริบทการเรียกแล้วไม่มีใครขานรับ
- ตัวอย่างการนับรอยเท้า: «แต่บนพื้นเริ่มมีรอยเท้าเปียกน้ำปรากฏขึ้นทีละรอย หนึ่ง... สอง... สาม... รอยเท้าหยุดอยู่ห่างจากเขาไม่ถึงสองเมตร» — รวมการนับในจังหวะเดียว ไม่แยกสามย่อหน้า

## Dialogue samples: user feedback

### 1. คนทั่วไป
- หลีกเลี่ยง «กู/มึง» เป็นค่าเริ่มต้น แม้คนคุยจะสนิทกัน
- ใช้ชื่อ คำแทนตัวที่สุภาพแบบกันเอง หรือการละสรรพนามตามธรรมชาติ
- ไม่ใช่คำห้ามเด็ดขาดสำหรับตัวละครอื่นในอนาคต แต่ไม่ควรใช้โดยไม่มีเหตุผลด้านบุคลิก/บริบท

### 2. เจ้าหน้าที่ภาคสนาม
- ให้คำสั่งสัมพันธ์กับหน้าที่และการควบคุมสถานการณ์ ไม่ใช่พูดสั้นแข็งเพื่อให้ดูมืออาชีพ
- ผู้เขียนแก้ «ยังไม่รู้ อย่าเพิ่งสรุป» เป็น:
  «อย่าพึ่งสนใจอย่างอื่นดูเครื่องตรวจไว้ เรายังไม่รู้ว่าเกิดอะไรขึ้น»
- ความหมายที่ต้องรักษา: เบี่ยงความสนใจกลับไปที่การตรวจเครื่องมือ และยอมรับความไม่แน่ชัด
- เมื่อเกลาเป็นประโยคในต้นฉบับ ให้รักษาน้ำเสียงและความหมาย เช่น «อย่าเพิ่งสนใจอย่างอื่น ดูเครื่องตรวจไว้ก่อน เรายังไม่รู้ว่าเกิดอะไรขึ้น» (การสะกด/เว้นวรรคเกลาได้ ไม่เปลี่ยนเจตนา)

### 3. เจ้าหน้าที่สอบสวนกับพระเอก
- ผู้เขียนอนุมัติตัวอย่างเดิม: สอบถามเป็นขั้นตอน สุภาพ ติดตามรายละเอียด แสดงความคิดของพระเอกผ่านคำตอบและข้อสังเกต

### 4. ผู้บริหารองค์กร
- ผู้เขียนอนุมัติตัวอย่างเดิม: เป็นทางการพอเหมาะ มีความเห็นต่างและความสัมพันธ์เชิงอำนาจ แต่ไม่พูดเหมือนอ่านประกาศ

### 5. พระเอกกับนักวิจัย
- ผู้เขียนแก้บทตอบสั้น:
  เดิม: «แล้วถ้าหาไม่ได้?» / «ก็ยังยืนยันไม่ได้»
  ใหม่: «แล้วถ้าหาไม่ได้» / «เราก็ยังยืนยันไม่ได้ค่ะ แต่เรื่องแบบนี้กับงานที่เราทำก็ไม่ค่อยมีอะไรที่ยืนยันได้แน่นอนอยู่แล้วค่ะ»
- หลักที่ได้: นักวิจัยตอบครบประเด็น ตรงไปตรงมา มีบริบทงาน และยังเป็นภาษาพูดธรรมชาติ; ไม่จำเป็นต้องตอบห้วนเพื่อสร้างความลึกลับ

### 6. พระเอกกับ Entity
- ผู้เขียนอนุมัติตัวอย่างเดิม: ระมัดระวัง ถามทีละประเด็น Entity อาจใช้ภาษาปกติได้ ความผิดปกติมาจากเนื้อหาหรือสถานการณ์

### 7. พระเอกกับหัวหน้าหน่วย
- ผู้เขียนอนุมัติตัวอย่างเดิม: พระเอกแย้งด้วยข้อมูล หัวหน้าปรับการตัดสินใจเมื่อมีหลักฐานใหม่
