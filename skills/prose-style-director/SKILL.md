# Prose Style Director

สร้างร้อยแก้วที่ฟังเป็นเสียงเดียวกับเรื่องและทำหน้าที่ของฉาก โดยไม่รอคำสั่งย่อยเรื่องการเลือกคำทุกครั้ง

## ขั้นตอนทำงาน

ใช้ลำดับนี้กับงานเขียนและงานแก้ภาษา:

1. **Calibrate** — อ่านข้อความรอบข้าง style profile และคำแก้เดิมของผู้ใช้ ระบุเสียงหลักกับระดับภาษา
2. **Draft for meaning** — เขียนให้การกระทำ ความคิด ผู้กระทำ และเหตุผลชัดก่อน
3. **Style pass** — เติมจังหวะ ภาพ และน้ำเสียงเท่าที่ฐานสไตล์ต้องการ
4. **Natural-language gate** — ตัดคำแปลตรง คู่คำประหลาด ภาษาหรูผิดเสียง และประโยคที่ไม่เป็นความคิดภาษาไทย
5. **Continuity pass** — ตรวจสรรพนาม คำเรียก ศัพท์เฉพาะ และเสียงของ POV
6. **Deliver** — ส่งข้อความที่แก้แล้ว ไม่ส่งร่างดิบหรือรายการกระบวนการคิด เว้นแต่ผู้ใช้ขอคำอธิบาย

เมื่อยังไม่มั่นใจวิธีแก้อาการหนึ่ง ให้อ่าน [ตัวอย่างแก้ภาษาไทย](references/thai-prose-examples.md) แล้วเทียบชนิดของปัญหา ไม่คัดลอกถ้อยคำจากตัวอย่างมาเป็นสูตรสำเร็จ

## ก่อนเขียน

1. อ่าน style profile ของเรื่องถ้ามี แล้วรักษาข้อกำหนดที่ล็อกไว้
2. ระบุฐานของสำนวนหนึ่งแบบ และตัวปรับไม่เกินสองแบบจาก [คลังสไตล์](references/style-library.md)
3. อนุมานระดับภาษา ระยะห่างจากตัวละคร ความเร็ว และความหนาแน่นของภาพจาก POV ประเภทฉาก และข้อความก่อนหน้า
4. ถ้าหลักฐานไม่พอ ใช้ค่าเริ่มต้นแบบโปร่งใส: ภาษาร่วมสมัย ชัดเจน ภาพพอดี จังหวะปานกลาง และใกล้ตัวละครเท่าที่ POV อนุญาต
5. สำหรับงานภาษาไทย อ่านและใช้ [ด่านภาษาธรรมชาติ](references/natural-thai-prose.md) เป็นข้อกำหนด ไม่ใช่ตัวเลือกด้านสไตล์
6. สำหรับนิยายกำลังภายในหรือยุทธภพ อ่านและใช้ [กำลังภายในฉบับไทยอ่านลื่น](references/wuxia-readable-thai.md) เพื่อคุมศัพท์เฉพาะและความครบของภาษา

อย่าหยุดถามเรื่องตัวเลือกที่ย้อนแก้ได้ ถ้าการเลือกนั้นไม่เปลี่ยนเจตนาหลักของผู้ใช้

## ระหว่างเขียน

- เลือกคำจากความหมาย น้ำเสียง ผู้รับรู้ และผลต่อจังหวะ ไม่เลือกคำยากเพียงเพื่อให้ดูมีชั้นเชิง
- ใช้คำนามและกริยาที่เฉพาะเจาะจงก่อนเพิ่มคำขยาย
- ให้รายละเอียดผ่านสิ่งที่ตัวละครนี้น่าจะสังเกต ไม่ผ่านรายการบรรยายกลางๆ
- ให้บทสนทนาสะท้อนภูมิหลัง ความสัมพันธ์ เป้าหมาย และสิ่งที่ตัวละครไม่ยอมพูด
- เมื่อฉากมีบทพูด ให้ใช้ `dialogue-and-narration` เพื่อตรวจความห้วน การยัดคำอธิบาย และเส้นแบ่งระหว่างคำพูด ความคิด กับคำบรรยาย
- เปลี่ยนความยาวประโยคอย่างมีหน้าที่: สั้นเพื่อแรงกระแทกหรือความเร่ง ยาวเพื่อการไหล การครุ่นคิด หรือการสะสมแรงกดดัน
- รักษาคำศัพท์เฉพาะ ชื่อเรียก และระดับสรรพนามให้ต่อเนื่อง
- ถ้าไม่แน่ใจว่าคำหรือวลีเป็นธรรมชาติหรือไม่ ให้เขียนความหมายเดียวกันด้วยภาษาที่คนไทยใช้จริงก่อน ความแปลกใหม่ต้องมีประโยชน์มากกว่าความสะดุด

อ่าน [หลักการเลือกคำและสร้างประโยค](references/diction-and-sentence-craft.md) เมื่องานเน้นการขัดเกลาภาษา แก้สำนวน หรือวินิจฉัยว่าข้อความแบน ฟุ้ง หรือซ้ำ

## การปรับตามฉาก

รักษาฐานของเรื่องไว้ แล้วเปลี่ยนเฉพาะตัวปรับที่จำเป็น:

- ฉากต่อสู้หรือไล่ล่า: ลดคำอธิบายที่หยุดเวลา เน้นกริยา การตัดสินใจ และผลกระทบทันที
- ฉากอารมณ์: เพิ่มพื้นที่ให้ปฏิกิริยาเฉพาะตัวและความหมายแฝง ไม่อธิบายอารมณ์ซ้ำหลังแสดงให้เห็นแล้ว
- ฉากสืบสวน: คุมลำดับข้อมูล แยกสิ่งที่เห็น สิ่งที่ตีความ และสิ่งที่ยังไม่รู้
- ฉากสยองขวัญ: ใช้ช่องว่าง ความคลาดเคลื่อน และรายละเอียดผิดปกติ ก่อนเปิดเผยตรงๆ
- ฉากตลก: คุมจังหวะ setup, turn และ payoff; อย่าอธิบายมุกหลังมุกทำงาน
- ฉากโรแมนติก: ให้น้ำหนักกับการเลือก ความเสี่ยง และการรับรู้กัน มากกว่าคำคุณศัพท์สำเร็จรูป

## ตรวจร่างก่อนส่ง

ทำ natural-language gate ก่อน แล้วแก้เองเมื่อพบข้อบกพร่องพื้นฐานต่อไปนี้:

- คำซ้ำหรือโครงประโยคซ้ำโดยไม่มีเจตนา
- คำขยายซ้อน แต่ภาพหรือความหมายไม่ชัดขึ้น
- สำนวนหลุดจาก POV หรือระดับภาษาของตัวละคร
- บอกอารมณ์ซ้ำกับการกระทำ บทสนทนา หรือภาพที่สื่อไปแล้ว
- อุปมาไม่อยู่ในโลกประสบการณ์ของผู้รับรู้ หรือมีหลายภาพแย่งกันในย่อหน้าเดียว
- ทุกประโยคมีน้ำหนักเท่ากันจนไม่มีจุดเน้น
- ภาษาสวยแต่ทำให้การกระทำ ตำแหน่ง หรือเหตุและผลคลุมเครือ
- คำเด่นที่ดึงความสนใจมาหาตัวเองโดยไม่เพิ่มภาพ น้ำเสียง ความหมาย หรือจังหวะ
- โครงสร้างที่เหมือนแปลจากภาษาอื่น แม้แต่ละคำจะแปลถูก
- คำที่อยู่ร่วมกันได้ตามไวยากรณ์แต่ไม่ใช่คู่คำที่คนไทยใช้ตามธรรมชาติ
- คำนามแกนกลางถูกตัดออกเพื่อทำให้ภาษาดูกระชับหรือโบราณ จนผู้อ่านต้องเติมความหมายเอง
- ศัพท์เฉพาะปรากฏโดยไม่มีบริบทพอให้เข้าใจ และไม่มีเหตุผลต้องใช้แทนคำไทยทั่วไป

เมื่อแก้ต้นฉบับของผู้ใช้ ให้รักษาเจตนา ข้อมูล และเสียงเดิมก่อนเพิ่มรสนิยมของเอเจนต์ หากต้องเปลี่ยนฐานสไตล์ของทั้งเรื่อง ให้เสนอเหตุผลและตัวอย่างสั้นก่อนเปลี่ยนวงกว้าง
