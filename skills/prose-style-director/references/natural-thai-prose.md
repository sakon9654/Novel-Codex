# ด่านภาษาไทยที่เป็นธรรมชาติ

ใช้ด่านนี้กับร่างภาษาไทยทุกชิ้นหลังเขียนและก่อนส่ง เป้าหมายไม่ใช่ทำให้ภาษาจืด แต่ทำให้คำเด่นเฉพาะเมื่อมีเหตุผลทางเสียง ภาพ ตัวละคร หรือความหมาย

## ค่าเริ่มต้น

- ใช้ภาษาไทยร่วมสมัยที่เจ้าของภาษาอ่านแล้วไม่ต้องแปลกลับในหัว
- เมื่อสองทางเลือกสื่อความหมายได้เท่ากัน ให้เลือกทางที่เป็นธรรมชาติและไม่เรียกร้องความสนใจ
- ใช้คำโบราณ คำถิ่น ศัพท์เฉพาะ หรือถ้อยคำประดิษฐ์ได้เมื่อโลก ผู้เล่า หรือตัวละครรองรับ
- ความเป็นวรรณศิลป์เกิดจากการคัดเลือกภาพ จังหวะ และความหมาย ไม่ใช่จากการแทนคำธรรมดาด้วยคำหรูทุกจุด

## Natural-language gate

### 1. Translation pass

ตรวจว่าประโยคยังแบกโครงจากภาษาอื่นหรือไม่ โดยเฉพาะ:

- สรรพนามถูกกล่าวซ้ำทั้งที่ภาษาไทยละประธานได้ชัดเจน
- อวัยวะถูกทำให้เป็นผู้กระทำโดยไม่มีเหตุผล เช่น มือหรือดวงตาเหมือนแยกจากเจ้าของ
- ใช้โครง `พบว่าตัวเอง...`, `มันรู้สึกเหมือน...`, `ให้ความรู้สึกของ...` หรือคำนามนามธรรมต่อกันเพราะแปลตามรูปประโยคเดิม
- บอกความเป็นเจ้าของทุกตำแหน่ง เช่น มือของเขา ดวงตาของเธอ ทั้งที่บริบทชัด
- ใช้คำเชื่อมและคำขยายในตำแหน่งที่ถูกไวยากรณ์แต่ฝืนจังหวะไทย

อย่าลบโครงเหล่านี้แบบอัตโนมัติ ให้เขียนใหม่เมื่อประโยคฟังเหมือนคำแปลมากกว่าความคิดภาษาไทย

### 2. Collocation pass

ตรวจคำที่วางคู่กันว่าเจ้าของภาษาใช้จริงในความหมายนี้หรือไม่ คำสองคำอาจถูกแยกกันแต่แปลกเมื่ออยู่ร่วมกัน

ถามกับคำหรือวลีที่สะดุด:

1. คนในระดับภาษานี้จะพูด คิด หรือเล่าแบบนี้จริงหรือไม่
2. คำนี้จับกับกริยา คำนาม หรือคำขยายข้างๆ ตามธรรมชาติหรือไม่
3. มีคำธรรมดากว่าที่แม่นเท่ากันหรือแม่นกว่าหรือไม่

ถ้าตอบข้อแรกหรือข้อสองไม่ได้ และคำนี้ไม่มีหน้าที่ชัด ให้เปลี่ยน

### 3. Odd-word pass

อ่านทีละย่อหน้าแล้วชี้คำหรือวลีที่ “สะดุดที่สุด” หนึ่งจุด จากนั้นพิจารณาว่ามันเพิ่มอะไร:

- ภาพชัดขึ้น
- เปิดเผยตัวละครหรือผู้เล่า
- สร้างนัยหรือบรรยากาศ
- คุมจังหวะหรือแรงกระแทก
- เป็นศัพท์ของโลกที่ต้องรักษา

ถ้าไม่เพิ่มสิ่งใด ให้แทนด้วยคำที่เงียบและตรงกว่า หากไม่มีคำใดสะดุด ไม่ต้องฝืนแก้

### 4. Mouth-and-ear pass

- บทสนทนาต้องพูดออกเสียงได้ตามวัย ภูมิหลัง ความสนิท และสถานการณ์
- ความคิดใกล้ชิดต้องเป็นคำที่ตัวละครน่าจะคิด ไม่ใช่คำของผู้บรรยายที่เข้ามาอธิบายแทน
- อ่านจังหวะในใจ ถ้าต้องย้อนอ่านเพื่อรู้ว่าใครทำอะไร ให้แก้ลำดับข้อมูลก่อนแต่งถ้อยคำ

## สัญญาณเตือน ไม่ใช่คำต้องห้าม

กลุ่มต่อไปนี้ต้องตรวจหน้าที่ทุกครั้ง ไม่ได้แปลว่าห้ามใช้:

- ภาพสำเร็จรูปหรือคำขยายที่พบบ่อยจนไม่สร้างภาพใหม่ เช่น ความเงียบที่ “แผ่คลุม” สายตาที่ “สั่นไหว” ริมฝีปากที่ “ยกโค้ง”
- คำบอกเสียงซ้อนความหมาย เช่น `เสียงทุ้มต่ำ` เมื่อบริบทไม่ได้ต้องแยกคุณสมบัติทั้งสอง
- คำกายภาพที่ใช้แทนอารมณ์ซ้ำๆ เช่น หัวใจบีบรัด ลมหายใจสะดุด ร่างแข็งค้าง
- คำยกระดับที่ไม่ตรงเสียงของ POV เช่น `พลัน`, `บัดนั้น`, `หาได้...ไม่`, `ประหนึ่ง` ในเรื่องร่วมสมัย
- วลีที่อธิบายผลหลังภาพทำงานแล้ว เช่น บอกว่าบรรยากาศตึงเครียดหลังแสดงความตึงเครียดครบถ้วน
- การใช้ `อย่าง` และคำนามนามธรรมหลายชั้นจนการกระทำไม่เหลือแรง

ใช้ได้เมื่อเหมาะกับเสียงและจังหวะ แต่ห้ามใช้เพียงเพราะเป็นภาษาที่ดูเหมือนนิยาย

## การเรียนรู้จากคำแก้ของผู้ใช้

เมื่อผู้ใช้ชี้ว่าคำหนึ่งแปลก:

1. แก้ตำแหน่งนั้นตามเจตนา
2. ระบุชนิดของปัญหา เช่น คำแปลตรง คู่คำผิดระดับ เสียงตัวละครหลุด หรือภาพสำเร็จรูป
3. ตรวจร่างปัจจุบันหาอาการชนิดเดียวกัน ไม่ค้นเฉพาะคำเดิม
4. บันทึกตัวอย่างใน style profile ของเรื่องถ้าเป็นความชอบหรือเสียงเฉพาะโปรเจกต์
5. อย่ายกระดับคำแก้เฉพาะเรื่องเป็นกฎสากล เว้นแต่เป็นปัญหาภาษาเดียวกันอย่างชัดเจน

## เกณฑ์ผ่าน

ข้อความผ่านเมื่อคำเด่นทุกคำมีเหตุผล ประโยคอ่านเป็นความคิดภาษาไทย ผู้เล่ากับตัวละครไม่หลุดระดับ และผู้อ่านสนใจสิ่งที่เกิดขึ้นมากกว่าสังเกตว่าเอเจนต์พยายามเขียนให้สวย
